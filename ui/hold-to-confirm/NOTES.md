The seed exploration, built to prove out the pipeline: one HTML file, Tailwind compiled at build time, and a page that switches frame widths.

The detail that makes it work is the label drawn twice: a dark copy under the fill and a light copy clipped to the fill's edge, so the text changes color right where the fill reaches it.
